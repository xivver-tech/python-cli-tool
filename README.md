# Python CLI Tool

A simple interactive command-line calculator written in pure Python.

## Requirements

- Python 3.6+

## How to run

```bash
python calculator.py
```

Then type expressions like:

```
> 2 + 3
= 5
> 10 * 4
= 40
> quit
```

Supports basic arithmetic: `+`, `-`, `*`, `/`, `**`, parentheses, etc.
